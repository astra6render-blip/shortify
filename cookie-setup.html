Only getting a few cookies? Try the full cookie-file method

The console shows only non-HttpOnly cookies, which is usually enough. If YouTube still refuses, export the complete cookie jar:

  1. In Chrome install the extension “Get cookies.txt LOCALLY”.
  2. Visit youtube.com, click the extension, choose Export.
  3. It downloads cookies.txt. Open it in Notepad / TextEdit.
  4. Select all of it, copy, and paste into the box above.

Both formats are accepted — the server detects which one you pasted.
